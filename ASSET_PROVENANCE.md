# Asset provenance register

## Visual assets

The publisher has stated that all visual assets in this project were created
with generative AI and then prepared for the game by the developer. This
includes characters, enemies, bosses, motorcycles, backgrounds, effects,
portraits, user-interface artwork, icons, and promotional artwork derived from
those assets.

Before Steam review, attach an export or archive containing the prompts,
generation outputs, source images, tool/provider, model/version, creation date,
applicable commercial-use terms, and a short description of human edits for
